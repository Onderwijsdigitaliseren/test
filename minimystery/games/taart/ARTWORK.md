# Artwork – Wie heeft de taart gepakt? (games/taart/img)
Alles optioneel: het spel tekent de verdachten zelf (SVG) als een bestand ontbreekt. Een bestand met deze naam wint.
Formaat: webp, vierkant waar het een gezicht is.

| Bestand | Wat | Formaat |
|---|---|---|
| hero.webp | sfeerbeeld startscherm: feestkeuken, lege taartschaal met kruimels | 1080×1080 (bovenkant zichtbaar) |
| kruimel.webp | Inspecteur Kruimel (muis in regenjas) | 400×400, nog niet gebruikt |
| taart.webp | de teruggevonden, gedeukte taart (eindscherm) | 1080×600 |
| diploma-stempel.webp | stempel voor het diploma | 400×400 rond |
| toos.webp | Oma Toos: paarse sjaal, hoedje met bloem, bril | 400×400 |
| bertus.webp | Opa Bertus: groene pet, grote snor, bril | 400×400 |
| fien.webp | Buurvrouw Fien: rode schort, pollepel, geen hoed | 400×400 |
| teun.webp | Neefje Teun (4): gele pet achterstevoren, klein | 400×400 |
| bo.webp | Hond Bo: blauwe halsband, natte neus | 400×400 |
| mimi.webp | Kat Mimi: roze strikje | 400×400 |
| plek-schuur.webp, plek-koelkast.webp, plek-zolder.webp, plek-bank.webp, plek-boom.webp | de vijf verstopplekken (deel 2) | 400×400 |

Let op: de kenmerken moeten kloppen met de sporen: vacht (Bo, Mimi), iets op het hoofd (Toos, Bertus, Teun), klein (Teun, Bo, Mimi), en per verdachte één kleur (paars, groen, rood, geel, blauw, roze). De schaduw-opdracht gebruikt altijd de getekende versie.
