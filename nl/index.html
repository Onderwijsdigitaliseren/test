Moordwandeling

Acht sporen op echte plekken om je heen.

De kaart legt de sporen op echte plekken om je heen: de kerk, de bushalte, het café. Jullie lopen erheen als team, puzzelen samen, sluiten verdachten uit en wijzen de dader aan.

Kies je wandeling

1

Probeer gratis: elke wandeling heeft een proefronde. Daarna koop je één ticket voor je team (€ 9,95). Iedereen vult dezelfde code in op zijn eigen telefoon. De code blijft twee maanden geldig, dus je start wanneer jij wilt.

2

Sta locatie toe en de kaart legt de sporen op echte plekken op loopafstand van waar je staat. Loop erheen. Binnen 35 meter gaat een spoor open: een schim die iets zag, een bewijsstuk, een camerabeeld, een bericht.

3

Puzzel het samen uit in het notitieboek: sluit verdachten uit, ontmasker de leugenaar en wijs de dader aan. Samen op één telefoon, of ieder op een eigen telefoon.
