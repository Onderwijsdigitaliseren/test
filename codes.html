Codes maken

Eén codelijst voor het hele platform: een Pro-code werkt in álle wandelingen (Moordwandeling, De Verdwijning en wat er nog komt), op beide domeinen. Deze pagina verstuurt niets; alles gebeurt op dit apparaat.

1. Nieuwe code

Deze code geef je aan kopers (zet hem in je Ko-fi-bericht): Deze regel plak je in codes.json, tussen de vierkante haken: De code zelf staat nergens in je bestanden. Bewaar hem dus zelf, bijvoorbeeld in Ko-fi.

2. Zo ziet codes.json eruit

Het bestand staat in de root van de repo (/codes.json) en wordt door elk spel via /shared/platform.js geladen. Het zout voor de hashes staat in platform.js (salt) en mag nooit veranderen.

  1. Elke code is één regel tussen accolades. Tussen twee regels staat een komma, na de laatste niet.
  2. "tot": na die datum kan de code niet meer nieuw worden ingevoerd. Een groepspas stopt dan ook, zelfs als de 48 uur nog niet om zijn. Pro blijft op toestellen waar het al aan stond.
  3. Bij een verkochte groepscode: zet "tot" op 7 dagen na de aankoop, bijvoorbeeld "tot":"2026-10-09".
  4. "uit":true: de code werkt nergens meer, ook niet op toestellen waar hij al was ingevoerd. Gebruik dit als een code is uitgelekt.
  5. Regel weghalen: de code kan niet meer nieuw worden ingevoerd. Bestaande Pro-toestellen blijven Pro.
  6. "naam" is alleen een geheugensteun voor jou. De app doet er niets mee.
